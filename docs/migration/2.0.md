# 1.1에서 2.0으로 이전

2.0으로 올릴 때 필요한 호출부 변경을 설명합니다. 공개 패키지 6개는 같은 버전을 사용하므로 직접 의존하는 `@connextable/popbill*` 패키지를 함께 올리고 TypeScript 타입 검사를 실행합니다.

```sh
npm install @connextable/popbill@^2.0.0
```

compat를 직접 사용하는 프로젝트는 `@connextable/popbill-compat@^2.0.0`을 설치합니다. 내부 패키지를 직접 의존하는 경우 해당 패키지도 같은 버전으로 맞춥니다.

## 응답 코드와 미확정 값

전자문서의 상태·결과·분류 코드와 플래그는 새 서버 값과 `null`을 보존합니다. 누락된 상태값 때문에 다건 조회 전체를 실패시키지 않습니다. 숫자 정수 문자열은 안전하게 해석할 수 있으면 숫자로 정규화하며, 앞자리 0이 의미 있는 국세청 결과코드·금액·식별번호는 원문을 유지합니다.

응답 플래그는 알려진 `true/false`, `Y/N`, `1/0` 표현을 정규화합니다. 그 밖의 값은 미확정 값으로 남으므로 단순 참·거짓 검사 대신 명시적으로 비교합니다. 아래 코드는 이미 생성한 `client`에서 문서를 조회하는 예입니다.

```ts
const info = await client.services.taxInvoice.getInvoiceInfo({
  businessNumber: '1234567890',
  invoiceDocumentKeyType: 'SELL',
  invoiceManagementKey: 'MY-KEY',
})

if (info.isOpen === true) {
  console.log('열람 완료')
} else if (info.isOpen === false) {
  console.log('미열람')
} else {
  console.log('열람 여부 미확정:', info.isOpen)
}
```

회원·아이디 확인과 수집 상태의 성공 플래그는 숫자 `1`과 숫자 문자열 `"1"`을 같은 결과로 판단합니다. 원본 결과코드는 유지하며, 알 수 없는 코드는 성공으로 추측하지 않습니다. 오류의 숫자 문자열 코드는 정규화된 `code`로 읽을 수 있고 원래 본문은 `raw`에 남습니다.

선택 수량·페이지·파일 크기의 `null`과 빈 값은 생략합니다. 문자 상태·결과코드는 숫자를 문자열로 정규화하되 `null`과 누락을 보존합니다. 호출부에서 새 출력 타입의 `string`·`null`·`undefined` 가능성을 처리합니다. 요청 인자의 허용 범위와 필수 구조·HTTP 오류 처리는 유지합니다.

## 기존 scaffold와 추가 서비스

1.1의 미구현 서비스 scaffold를 실제 HTTP 호출로 대체했습니다. 세금계산서 `getUnitCost`의 기존 `Promise<number>` 선언도 공식 계약의 `Promise<string>`으로 수정했습니다. 당시 함수는 미구현 상태였으며 숫자를 반환하던 동작이 바뀐 것은 아닙니다. modern은 `{ unitCost: string }` 형태로 제공합니다. 문자열은 공식 계약의 타입 선언이며, 서버에서 숫자를 받았을 때 오류를 내거나 값을 버리는 검증은 추가하지 않았습니다.

compat는 공식 레거시 함수 이름과 위치 인자·callback·Promise API를 제공합니다. modern은 객체 인자와 목적별 함수 이름을 사용하며 호환 별칭을 추가하지 않습니다. 전체 서비스와 메서드는 [구현 범위](./service-coverage.md)와 [SDK 레퍼런스](../sdk/README.md)에서 확인합니다.

공동인증서 직접 등록 `RegistTaxCert`·`RegistTaxCertPFX`는 지원 범위에서 제외합니다. 기존 인증서 등록 팝업 URL 방식은 제공합니다. 공식 SDK 메서드 대조와 로컬 HTTP mock 검증은 실서버의 계정별 권한·레거시 API 이용 가능성 확인과 구분합니다.

응답 처리의 상세 기준은 [외부 API 계약 검증](./service-coverage.md#외부-api-계약-검증), 실제 검사 결과와 미검증 범위는 [검증 기록](./validation-history.md)을 확인합니다.
